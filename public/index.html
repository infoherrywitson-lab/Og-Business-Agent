FAQ

Straight answers.

Does Business OS publish, spend or deploy on its own?

No. Approving an item records a human decision and nothing more. There are no external integrations wired in by default, and publishing, ad spend, purchases, deployments and bulk outreach are approval-gated by design.

Which languages can I write a brief in?

English, Urdu script and Roman Urdu. The planner detects the language and tags it on the saved plan, so mixed-language teams can work from the same workspace.

Do I need an AI API key?

No. Without a key, a deterministic rules-based planner produces the full agent/task plan. Add an OpenAI-compatible AI_API_KEY later to get AI-assisted summaries and deliverables — the key stays server-side, never in the browser.

Where does my data live?

In a local JSON store written atomically on your own server — one workspace per process. A Supabase schema ships in the repo as the documented path to multi-user, multi-workspace storage.

What does it cost?

The core is free-first: Node.js built-ins only, no runtime npm dependencies, no vendor lock-in. The only optional cost is usage on an AI provider you already choose to connect.
